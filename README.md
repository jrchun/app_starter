# 앱 시작 틀 (app_starter)

나와 친구 몇 명이 쓰는 **작은 웹 앱**을 Claude Code로 만들고, 무료로 인터넷에 올리기 위한 틀입니다.
개발을 몰라도 아래 순서만 따라 하면 됩니다. 코드는 Claude가 쓰고, 사람은 로그인 버튼 몇 번과 편집 암호만 넣습니다.

> 예: 가계부, 운동 기록, 모임 회비 장부, 투자 비중 계산기처럼 "나(와 몇 명)만 쓰는 도구"에 맞습니다.
> 회원가입·결제가 필요한 큰 서비스에는 맞지 않습니다.

---

## 가장 쉬운 방법: AI에게 맡기기

Claude Code나 Codex에 이 저장소 주소와 만들고 싶은 것을 그대로 말하세요.

> https://github.com/jrchun/app_starter 로 운동 기록 앱을 만들어서 배포까지 해 줘. 날짜별로 종목·무게·횟수를 적고 폰에서 주로 쓸 거야.

AI가 [`docs/AGENT_SETUP.md`](docs/AGENT_SETUP.md)를 읽고 저장소 만들기 → 개발 → 데이터베이스 → 배포 → 실제 사이트 확인까지 진행합니다.
사람이 할 일은 **저장소 만들기, 기획 요약 확인, 승인 창 허락, 사이트에서 편집 암호 정하기**가 거의 전부입니다(처음 앱에서는 Cloudflare 버튼 몇 번이 더). 토큰을 만들 필요는 없습니다.

- 내 컴퓨터에서 Claude Code·Codex를 쓰면 거의 전부 자동입니다.
- claude.ai 웹 같은 클라우드에서 쓰면 저장소 만들기와 승인 창은 직접 눌러야 합니다(아래 "새 앱 만들기").

### 데이터 저장 방식 고르기

| | D1 모드 (기본) | Supabase 모드 |
|---|---|---|
| 이런 앱 | 가계부, 회비 장부처럼 나(와 몇 명)가 **같은 데이터**를 함께 봄 | 운동 인증처럼 **사람마다 로그인**하고 자기 데이터를 봄 |
| 로그인 | 없음. 고치려면 편집 암호 | 이메일·비밀번호 |
| 읽기 | 주소를 아는 누구나 | 본인만 |
| 무료 한도 | 넉넉함 | 계정당 프로젝트 2개 |

모르겠으면 AI에게 앱 설명만 하면 맞는 쪽을 추천합니다.

## 새 앱 만들기 (직접 따라 하기)

### 1. 내 저장소 만들기 (1분)

1. 이 링크를 엽니다: **https://github.com/new?template_name=app_starter&template_owner=jrchun**
   (또는 이 페이지 위쪽 초록색 **Use this template** › **Create a new repository**)
2. Repository name에 **앱 이름**을 영문 소문자와 하이픈으로 적습니다 (예: `gym-log`). 이 이름이 사이트 주소가 됩니다.
3. Public / Private 아무거나 고르고 **Create repository**

> 버튼이 안 보이면 GitHub에 로그인했는지 확인하세요.

### 2. Claude Code에서 시작하기

1. claude.ai/code에서 새 세션을 열고, 방금 만든 저장소를 고릅니다.
2. 만들고 싶은 것을 평소 말투로 적고 "배포까지 해 줘"라고 덧붙입니다.

   > 운동 기록 앱 만들어서 배포까지 해 줘. 날짜별로 종목·무게·횟수를 적고, 이번 주 합계를 보여 줘. 폰에서 주로 쓸 거야.

3. Claude가 기획 요약(화면·기능·저장 방식·**사이트 주소**)을 한 번 보여 주고 확인을 받습니다. 예: "사이트 주소는 `https://gym-log.내계정.workers.dev`가 됩니다." 처음 쓰는 Cloudflare 계정이면 주소 가운데 들어갈 **계정 이름**도 이때 고릅니다(한 번 정하면 바꿀 수 없음). 그다음 만들고, 테스트하고, 화면 캡처까지 확인한 뒤 보고합니다. 마음에 안 드는 곳은 그대로 말하면 고칩니다.

### 3. 인터넷에 올리기 (처음 한 번)

**토큰이나 열쇠 같은 값을 만들 필요가 없습니다.** Claude가 데이터베이스를 만들고, 변경을 합치고(Merge), Cloudflare에 올리는 것까지 합니다.
사람이 할 일은 아래뿐입니다. 자세한 순서와 흔한 실수는 [`docs/SETUP.md`](docs/SETUP.md)에 있습니다.

| # | 할 일 | 언제 |
|---|---|---|
| ① | Cloudflare **로그인 버튼** 누르기. claude.ai는 설정 › 커넥터 › 사용자 지정 커넥터 › `https://mcp.cloudflare.com/mcp`. 권한 화면이 나오면 **Workers CI**까지 허용 | 처음 한 번 |
| ② | claude.ai에서 "사이트 주소에 접속하게 해 달라"는 **승인 창**이 뜨면 허락 | 앱마다 한 번 |
| ③ | Claude가 "Cloudflare 연결을 대신 못 했다"고 하면: Cloudflare › Workers 및 Pages › **만들기** › **GitHub** › 내 저장소 › **배포** (처음이면 GitHub에서 Cloudflare 앱 설치를 허락. **모든 저장소** 허용을 고르면 다음 앱부터는 Claude가 합니다) | 보통 처음 앱에서만 |
| ④ | Claude가 준 주소를 폰에서 열고 아무 값이나 고치면 **"편집 암호 정하기"**가 뜹니다. 6자 이상으로 정하면 끝 (주소를 다른 사람에게 보내기 **전에** 하세요) | 앱마다 한 번 |

끝나면 Claude가 사이트(`https://앱이름.내계정.workers.dev`)를 직접 검사하고 결과를 알려 줍니다.

> **꼭 기억할 것**
> - 편집 암호는 **채팅에 쓰지 마세요.** 사이트 화면에만 넣습니다. 잊으면 Claude에게 "편집 암호 초기화해 줘"라고 하면 다시 정할 수 있습니다.
> - 매일 자동 작업은 Cloudflare 안에서 돕니다(따로 설정할 것 없음). 무료 플랜은 계정 전체에서 5개 앱까지 매일 작업을 쓸 수 있습니다.

### 4. 그다음부터

- 고치고 싶으면 Claude에게 말하면 됩니다. Claude가 고치고, 테스트하고, 합치면(Merge) 사이트가 자동으로 바뀌고, Claude가 실제 사이트를 확인합니다. 합치기 전에 보고 싶으면 "합치기 전에 보여 줘"라고 하세요.
- 사이트 주소를 친구에게 보내면 **누구나 볼 수 있고**, **편집 암호를 아는 사람만 고칠 수 있습니다.**
- 편집 암호는 기기마다 처음 한 번만 넣으면 그 기기에 기억됩니다.

## 데이터는 어디에 저장되고, 편집 암호는 왜 필요한가요 (D1 모드)

### D1은 창고입니다
**D1은 Cloudflare가 제공하는 데이터베이스**(값을 오래 보관하는 창고)입니다. 내 Cloudflare 계정 안에 있고, 무료 범위 안에서 씁니다.
사이트 화면(HTML 등)은 그냥 파일이라 스스로 값을 기억하지 못합니다. 그래서 입력한 값은 D1에 넣어 둡니다.

### 값이 저장되고 보이는 길

```
 폰 화면          Cloudflare
 ┌──────┐  저장   ┌──────────────┐  기록   ┌──────────┐
 │ 값 고침│ ─────▶ │ Worker(문지기)│ ─────▶ │ D1(창고) │
 └──────┘        └──────────────┘        └──────────┘
                        │ 읽기                 │
 PC 화면  ◀─────────────┘◀────────────────────┘
```

1. 폰에서 값을 고치면 0.7초 뒤 화면이 "이렇게 바꿔 주세요"라는 요청을 보냅니다.
2. 요청은 **Worker**(사이트 뒤에서 도는 작은 프로그램)가 먼저 받습니다.
3. Worker가 확인한 뒤 D1에 기록합니다.
4. PC에서 열면 Worker가 D1에서 값을 꺼내 보여 줍니다. 그래서 폰과 PC가 같은 값을 봅니다.

화면은 창고에 직접 들어가지 못하고 반드시 Worker를 거칩니다. 그래서 Worker가 **문지기**를 할 수 있습니다.

### 편집 암호는 문지기에게 보여 주는 열쇠입니다
이 방식에는 회원가입·로그인이 없어서, 문지기는 요청을 누가 보냈는지 모릅니다. 그래서 **암호를 아는가**로 구분합니다.

| 요청 | 문지기의 판단 |
|---|---|
| 보기 | 누구나 통과 (주소를 아는 사람은 볼 수 있음) |
| 고치기 | 편집 암호가 맞을 때만 통과, 틀리면 거절 |

- **정하는 때**: 앱을 처음 고칠 때 화면에 "편집 암호 정하기"가 뜹니다. 6자 이상으로 정하면 끝입니다. 정하기 전에는 아무도(본인 포함) 저장할 수 없습니다.
- **기기마다 한 번**: 한 번 넣으면 그 기기의 브라우저가 기억합니다. 같이 쓰는 사람에게는 같은 암호를 알려 주면 됩니다.
- **안전하게 보관**: Cloudflare에는 암호 원문이 아니라 되돌릴 수 없는 지문(해시)만 저장됩니다.
- **잊었을 때**: Claude에게 "편집 암호 초기화해 줘"라고 하면 다시 정할 수 있습니다.
- **덤**: 폰과 PC에서 동시에 고쳐 한쪽이 덮어쓰는 일은 저장할 때마다 붙는 버전 번호로 따로 막습니다("다른 기기에서 수정돼 새로 불러왔습니다").
- **로그인 대신 암호를 쓰는 이유**: 나 혼자 또는 몇 명이 같은 데이터를 쓰는 도구에는 가입 절차가 번거롭기만 합니다. 사람마다 자기 데이터만 보게 하려면 로그인이 있는 Supabase 모드를 고릅니다.

## 알아 두면 좋은 것

- **비용**: 작은 개인 앱이면 Cloudflare와 GitHub 무료 범위 안에서 충분합니다.
- **데이터는 공개입니다**: 사이트 주소를 아는 사람은 내용을 볼 수 있습니다. 남에게 보이면 안 되는 정보(주민번호, 계좌 비밀번호 등)는 넣지 마세요.
- **백업**: Claude에게 "데이터 백업해 줘"라고 하면 데이터베이스를 파일로 내려받는 방법을 안내합니다.
- **틀이 좋아지면**: 이 저장소가 바뀌어도 이미 만든 내 앱에는 자동으로 반영되지 않습니다. 필요한 부분만 Claude에게 옮겨 달라고 하세요.

## 안에 들어 있는 것 (Claude와 개발자용)

| 역할 | 무엇으로 | 위치 |
|---|---|---|
| 화면 | 정적 HTML·CSS·JS (빌드 없음) | `web/` |
| API | Cloudflare Worker | `src/` |
| 저장 | Cloudflare D1 (SQLite) | `db/schema.sql` |
| 매일 작업 | Cloudflare Cron Trigger | `src/jobs.js`, `wrangler.toml` `[triggers]` |
| 배포 | Cloudflare MCP(첫 배포), Workers Builds(이후 `main` 푸시마다) | `scripts/cf_mcp.mjs` |

- 문서 하나를 저장하는 API(`/api/doc`): 버전 관리, 다른 기기 동시 수정 시 409, 편집 암호 없으면 401
- 화면 동기화 모듈(`web/js/docsync.js`): 0.7초 뒤 자동 저장, 충돌 시 최신으로 교체, 화면 안 편집 암호 입력칸
- 라이트·다크 색 변수, 폰(400px) 기준 레이아웃
- `scripts/cf_mcp.mjs`(Cloudflare MCP로 D1 준비·배포·상태 확인), `scripts/check_site.mjs`(배포 검사), 테스트
- 작업 규칙은 [`CLAUDE.md`](CLAUDE.md), 배포 절차와 함정은 [`docs/SETUP.md`](docs/SETUP.md)
- 포함된 외부 코드(Supabase 브라우저 라이브러리, MIT)의 출처: [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)

```
npm test                                                  # 테스트
cp .dev.vars.example .dev.vars
npx wrangler@4 d1 execute my-app --local --file db/schema.sql
npx wrangler@4 dev                                        # http://localhost:8787
npm run check -- https://my-app.<계정>.workers.dev        # 배포 검사
```
